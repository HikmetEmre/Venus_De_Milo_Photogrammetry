Project Details

Photogrammetry Process

The model was created using photogrammetry with over 250+ photographs captured from every angle, including detailed coverage of the torso.

Post-Processing

Once photogrammetry was completed, the raw mesh was imported into Blender. Lighting, color balance, and surface tuning were refined, all transforms were applied, and the final optimized model was prepared for real-time use.

Deployment

The finalized model was exported for the web and deployed as an interactive 3D experience, supporting rotation, inspection, and mobile AR placement directly in the browser.
